=== D 1
ACTION: ADD
TITLE: Federated multi-task learning through a shared public-data representation space
PROPOSAL: We let each user keep an arbitrary encoder and task head, and coordinate only through embeddings of a small unlabelled public dataset that every user computes locally and sends to the server. The server learns a joint alignment objective over all users' embeddings at once, returns per-user alignment targets, and each user adds an alignment loss to its local task loss. We test on a benchmark mixing image classification, segmentation and text classification users with different backbones, including fine-tuned foundation models.
CONTROLS: Local training only, pairwise contrastive alignment between every pair of users, distillation on public logits restricted to same-task users, and a centered kernel alignment proximal term.
COST: 600
PREDICTION: Joint alignment should beat local training for most users and beat pairwise alignment when users number more than three. Users whose tasks share little with the rest may see no gain.
=== D 2
ACTION: ADD
TITLE: A volume-based contrastive loss for aligning many models at once
PROPOSAL: We propose a contrastive objective that treats the embeddings of one instance from all models as the columns of a matrix and rewards small volume of that matrix for positives relative to negatives, and we derive it as a lower bound on the total correlation among all representations. This gives a theoretical footing to Gramian-style alignment. We evaluate representation quality by linear probing on each model's task and by retrieval across models, with three to eight participating models.
CONTROLS: Pairwise contrastive alignment over all pairs, the existing Gramian loss without our normalisation, and independent training, with the number of models varied to show how each loss scales.
COST: 340
PREDICTION: The volume objective should match pairwise alignment with three models and pull ahead as more models join. The bound may become loose for very high-dimensional embeddings, reducing the advantage there.
=== D 3
ACTION: ADD
TITLE: Communication-efficient alignment by exchanging compressed public embeddings
PROPOSAL: We reduce the communication of representation-based federated multi-task learning by sending low-precision, randomly projected embeddings of public data instead of full ones, and by refreshing alignment targets only every few rounds. We characterise the trade-off between bytes exchanged and accuracy for users with heterogeneous architectures and tasks, and compare against parameter-sharing methods that need congruent encoders.
CONTROLS: Full-precision embeddings exchanged every round, parameter sharing of a common encoder where architectures allow it, and local training, with total uploaded bytes per user tracked alongside task metrics.
COST: 250
PREDICTION: Compressed embeddings should lose little accuracy while cutting traffic well below that of parameter sharing. Aggressive projection could collapse fine-grained structure needed by dense prediction tasks.
=== D 4
ACTION: ADD
TITLE: Cross-modal collaboration between image, text and audio users without shared parameters
PROPOSAL: We study users in different modalities who share a public paired dataset of images, captions and audio clips. Each user embeds only its own modality, and the server aligns all embeddings of the same public instance jointly, so knowledge moves between an image classifier, a text sentiment model and a speech command recogniser that never exchange weights. We measure each user's task accuracy against training on local data alone.
CONTROLS: Local training only, pairwise contrastive alignment between modalities, and a heuristic multi-modal regularisation method designed for two modalities, extended to three by summing its pairwise terms.
COST: 420
PREDICTION: Joint alignment should improve every user, with the largest gains for the user with the smallest local dataset. Without enough public paired data the alignment targets will be noisy and the benefit will shrink.
=== D 5
ACTION: ADD
TITLE: Privacy leakage of sharing public-data embeddings compared with sharing parameters
PROPOSAL: We quantify how much information about local training data leaks through the public-data embeddings that representation-based federated methods exchange, and compare it with leakage from shared encoder parameters. We run membership inference and attribute inference attacks against users with different architectures and tasks, using open image and text datasets as local data.
CONTROLS: Attacks on a user that shares nothing as a floor, attacks on parameter-sharing federated methods, and embeddings with added noise at several levels to trace the trade-off between accuracy and leakage.
COST: 180
PREDICTION: Embedding sharing should leak less than parameter sharing at equal accuracy. Users fine-tuned heavily on small datasets may still leak membership through their public-data embeddings.
=== D 6
ACTION: ADD
TITLE: When does cross-task transfer help in federated multi-task learning
PROPOSAL: We vary task relatedness systematically across users, from identical tasks to unrelated ones, by constructing user tasks from controlled splits of a large labelled image corpus, and measure the gain of joint representation alignment over local training for each user as a function of relatedness and local data size. Each user picks its architecture from a pool of convolutional and transformer backbones.
CONTROLS: Local training, a centralised upper reference that pools all data, and alignment with shuffled public instances as placebo.
COST: 290
PREDICTION: Gains should be largest for related tasks and small local datasets, and fall towards zero for unrelated tasks. Negative transfer may appear when one dominant user pulls the shared space towards its own task.
=== D 7
ACTION: ADD
TITLE: Server-side aggregation of alignment targets weighted by user agreement
PROPOSAL: We replace uniform averaging of public-data embeddings on the server by a weighting in which each user's contribution to the alignment target grows with its agreement with the other users on held-out public instances. This should limit the influence of users with poor or unrelated representations. We test with users of different architectures, including some with very little local data and some with noisy labels.
CONTROLS: Uniform averaging, median aggregation, local training, and a setting where the low-quality users are removed entirely as an upper reference.
COST: 230
PREDICTION: Agreement weighting should recover most of the gain of removing low-quality users without needing to identify them. If all users are weak, the weighting will have nothing reliable to anchor on.

=== A 2 0
ACTION: ADD
TITLE: How tight is a contrastive bound on total correlation across many models
PROPOSAL: We construct synthetic views where the total correlation among the representations of several models is known in closed form, Gaussian views with a shared latent and view-specific noise, and we train encoders with the joint contrastive objective that bounds total correlation. We then read the gap between the objective's value and the true total correlation as the number of models grows from three to twelve and as the embedding dimension grows, and we compare the gradient direction of the objective with that of the true quantity, since the bound is only useful if its optimum sits near the true optimum.
CONTROLS: A comparison with pairwise InfoNCE summed over all pairs and with the existing Gramian loss, a reference run with the true total correlation optimised directly where it is tractable, the same setting repeated with the number of negatives varied, and the bound gap measured against the closed-form value at every model count, over five seeds.
COST: 60
PREDICTION: The gap should stay small up to a dozen models and shrink with more negatives, with gradients aligned with the true ones. A gap that grows with the model count faster than for the pairwise sum refutes the usefulness of the bound.

=== A 3 0
ACTION: ADD
TITLE: Uploading embeddings only on drift to cut communication in federated alignment
PROPOSAL: We let each heterogeneous user upload its public-data embeddings only when they have drifted from the last uploaded version by more than a threshold in cosine distance, and let the server update alignment targets from whatever embeddings are current, so that traffic follows the pace of change and not a round clock. Users have different backbones and tasks, and the question is whether accuracy survives when most rounds carry few uploads. We measure per-user accuracy against bytes sent and received, with the threshold varied from strict to loose.
CONTROLS: A comparison with uploads every round at matched final accuracy and with uploads at a fixed period chosen to send the same bytes, a reference run with local training alone, the same setting repeated with the threshold varied across a wide range, and accuracy measured against total bytes on one curve per user, over five seeds.
COST: 130
PREDICTION: Drift-triggered uploads should reach the accuracy of every-round uploads at a small fraction of the bytes, and should do better than a fixed period at the same bytes. The scheme is disproved if a fixed period with the same bytes reaches the same accuracy, or if accuracy falls sharply at every threshold that saves traffic.
