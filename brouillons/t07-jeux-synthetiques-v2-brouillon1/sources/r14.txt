TITLE: Thin-lens defocus rendering as supervision for focal-stack depth
PROPOSAL: We train a two-branch network on focal stacks: a focal branch applies 1D convolutions along the stack axis to each pixel's sharpness profile, and a spatial branch applies 2D convolutions on each slice. Their fusion predicts depth and an all-in-focus image, and a differentiable thin-lens renderer re-synthesises the stack from both outputs using the calibrated aperture and focus distances, so that the circle of confusion at each pixel must match the observed blur. Training uses DDFF-12-Scene and FoD500 with ground-truth depth, plus the re-rendering loss on unlabelled smartphone sweeps.
CONTROLS: DDFFNet, DefocusNet and AiFDepthNet retrained on the same splits, a sum-of-modified-Laplacian focus measure with guided filtering, the same network with the renderer removed, and with either branch removed, evaluated by RMSE, absolute relative error and a depth-boundary error on edge pixels.
COST: 320
PREDICTION: The rendering loss should cut boundary error on abrupt depth changes and reduce speckle in low-texture regions compared with every learned baseline; if the renderer branch gives no gain over the fused network alone, the physical model adds nothing beyond the data.
=== D 2
ACTION: ADD
TITLE: Separating texture gradients from depth edges with focus-profile agreement
PROPOSAL: For each pixel we compute the sharpness profile across the stack and its argmax slice, then measure whether neighbouring pixels on each side of a strong image gradient share the same peak slice. A true depth edge separates two peaks, while a texture gradient sits on a single peak. We feed this agreement map, together with the raw stack, to a U-Net that predicts depth, and we add a loss term that penalises depth discontinuities where the agreement map says the peaks coincide. Experiments use DDFF-12-Scene, FoD500 and the Mobile Depth dataset.
CONTROLS: The same U-Net without the agreement map, a version receiving only an all-in-focus image, DefocusNet and DFV as learned references, and a Laplacian focus measure followed by bilateral smoothing, all scored on edge-only pixels and on textured flat regions found from ground truth.
COST: 240
PREDICTION: We expect boundary error to drop on textured flat surfaces, where baselines hallucinate relief, and the ablation without the agreement map should lose most of that gain. The method may fail on reflective surfaces whose peak slice is itself wrong.

ACTION: ADD
TITLE: Learned defocus simulation with a focal-axis regulariser
PROPOSAL: We train a self-supervised model that predicts depth and an all-in-focus image from a focal stack and reconstructs the stack through a learned, spatially varying blur whose kernel size we constrain to be monotone in the distance between the pixel's depth and each slice's focus distance. The monotonicity term regularises the focus behaviour so that sharpness must peak once along the focal axis, and we optimise a second term that smooths depth only across pixels whose sharpness profiles are correlated. We train on unlabelled smartphone sweeps and on 4D Light Field focal stacks, and we evaluate against metric ground truth on DDFF-12-Scene and FoD500.
CONTROLS: The same model with an unconstrained blur kernel, with the correlation-weighted smoothing replaced by an ordinary total-variation prior, AiFDepthNet trained with the same unlabelled data, DDFFNet trained with labels, and a classical sum-of-modified-Laplacian pipeline. Metrics are RMSE, absolute relative error and the fraction of pixels within a threshold ratio of ground truth.
COST: 400
PREDICTION: The monotone kernel should reduce ambiguous focus responses on fine textures and lower RMSE relative to the unconstrained model, with the largest gains on sparsely sampled stacks. If the unconstrained kernel does equally well, the physical constraint is already learned implicitly from the data.

COST: 260

TITLE: Slice-wise attention with focus-distance encoding for focal stacks
PROPOSAL: We build a model whose per-pixel encoder attends across slices using the slice focus distances as continuous positional codes, then passes the attended features to a spatial decoder with edge-aware upsampling. The attention lets the model compare sharpness between any two slices directly, which should help when the focus response is ambiguous, and the positional codes let it handle stacks of any length and spacing. Training uses DDFF-12-Scene and FoD500, and we test on stacks of lengths and spacings unseen in training.
CONTROLS: DefocusNet, DFV and DDFFNet retrained with the same data, a 3D convolutional encoder of equal size and inference time, the attention model without focus-distance codes, a classical Laplacian pipeline, and tests on stacks subsampled or re-spaced at inference, with RMSE, boundary error and errors on textured flat regions, over three seeds.
COST: 300
PREDICTION: The attention model should keep its accuracy on unseen stack lengths where the 3D encoder breaks down, and should beat it on abrupt depth changes. If removing the codes changes nothing, the model ignores focus geometry.

TITLE: Estimating lens parameters from focal stacks with a regression network
PROPOSAL: We train a network to regress the aperture, focal length and per-slice focus distance of a focal stack from the images alone, using DDFF-12-Scene and FoD500 where these values are known, with rendered stacks from NYU Depth v2 as additional data. Accurate self-calibration would let classical depth-from-focus pipelines run on stacks whose metadata is missing or coarse, as on many phones, and would also tell how far the thin-lens model holds for real lenses.
CONTROLS: Baselines are the metadata values themselves, a least-squares fit of the thin-lens model to Laplacian peak positions, and a model trained on rendered data only. We ablate the backbone size and the number of slices given to the regressor, and report relative error per parameter and the RMSE of a classical pipeline run with the predicted versus true parameters, over three seeds.
COST: 300
PREDICTION: The network should recover focus distances within a small relative error and aperture less well. If the downstream depth RMSE barely changes between predicted and true parameters, calibration is not the limiting factor.
