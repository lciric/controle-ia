TITLE: Anytime semantic segmentation by warping a past frame's features with event-derived motion
PROPOSAL: We encode the last RGB frame into dense semantic features once, estimate a continuous-time motion field from the event stream up to the query time with a recurrent event encoder conditioned on the target offset, and warp the frame features to that time before a light decoder predicts the semantic map. Only past and current events are used, so the method is causal, and the offset input makes it answer at any time inside the interval. We evaluate on driving datasets with paired events and labels, synthesising intermediate labels by interpolation where needed.
CONTROLS: Copying the last frame's segmentation, event-only segmentation, RGB-event fusion at the frame time, and a video interpolation method given the future frame as an upper reference.
COST: 420
PREDICTION: Accuracy should decay slowly with offset and stay well above the copied segmentation at long offsets. Newly appearing objects not visible in the last frame may be missed.

TITLE: Building anytime labels for the interval between low-rate frames
PROPOSAL: We construct an evaluation set for causal anytime segmentation by recording driving scenes with a high-rate camera and an event camera together, labelling the high-rate frames with a strong segmentation model followed by human correction, and then keeping only every tenth frame as model input. This yields dense ground truth at many offsets inside each interval, including scenes with sudden pedestrian crossings and vehicles cutting in.
CONTROLS: Agreement between two human correctors on a subset, comparison of the automatic labels with fully manual labels on a sample, and a check that event timestamps align with high-rate frames within the sensor tolerance.
COST: 160
PREDICTION: The dataset should expose a steady loss of accuracy with offset for frame-based methods. Label noise at object boundaries may limit how finely methods can be ranked.

TITLE: Fusing static context and sparse events with offset-conditioned cross-attention
PROPOSAL: We fuse a frozen image backbone's features from the last frame with a sparse event representation accumulated up to the query time, using cross-attention in which the event tokens query the image tokens and the time offset is added as a learned embedding. A decoder then outputs the semantic map at the queried time. We train on driving and drone sequences with labels at several offsets and test on intervals longer than seen in training.
CONTROLS: Concatenation fusion with the same backbones, event-only and image-only models, and the fused model without the offset embedding.
COST: 380
PREDICTION: Cross-attention fusion should beat concatenation at long offsets and in fast scenes. Offsets longer than seen in training may expose poor extrapolation of the offset embedding.

TITLE: Distilling a non-causal teacher into a causal anytime student
PROPOSAL: A teacher that sees both frames around the gap and the events, and so can interpolate, is trained first; a causal student that sees only the first frame and the events up to the query time is then trained to match the teacher's soft maps at sampled offsets alongside the labels. COST: 400
