TITLE: Measuring who gives and who gains in joint embedding alignment across heterogeneous users
PROPOSAL: We run joint alignment on public-data embeddings for a federation of eight users with different backbones, from small convolutional networks to vision and text transformers, and different tasks, including classification, segmentation and sentiment, and we rerun the whole federation with each user removed in turn. The difference in every remaining user's test metric when a given user is absent measures what that user contributes, so transfer across tasks and architectures can be read directly, and we relate the contribution to task overlap and to backbone capacity.
CONTROLS: A comparison with local training of each user on its own backbone at matched local epochs and with pairwise contrastive alignment over all pairs, a reference run with every user trained on the pooled data of its own task, the same setting repeated with the public data replaced by a second collection, and contributions measured against the spread across seeds of the full federation, over five seeds.
COST: 540
PREDICTION: Most users should gain from the federation, and the largest contributions should come from users with overlapping tasks and strong backbones. The hypothesis fails if removing any single user changes the others by less than the spread across seeds.

TITLE: Contribution of each user to joint alignment in a federation of eight
PROPOSAL: We build a federation of eight users whose backbones range from small convolutional networks to vision and text transformers and whose tasks span classification, segmentation and sentiment, align their public-data embeddings jointly on the server, and then train again with one user left out at a time. For each omission we record the change in the test metric of every other user, which gives a contribution table across tasks and architectures, and we study how these contributions line up with task overlap, backbone capacity and the metric reached by a single shared backbone trained on all tasks together.
CONTROLS: A comparison with local training of each user on the largest backbone in the federation at matched local epochs and with a single shared backbone trained on all tasks, a reference run with every user trained on the pooled data of a second federation, the same setting repeated with the public data replaced by a second collection, and contributions measured against the spread across seeds of the shared-backbone run, over five seeds.
COST: 540
PREDICTION: Most users should gain from the federation, and the largest contributions should come from users whose backbones are close to the largest one. The hypothesis fails if removing any single user changes the others by less than the spread across seeds of the shared-backbone run.

TITLE: How tight is a contrastive bound on total correlation across many models
PROPOSAL: We construct synthetic views where the total correlation among the representations of several models is known in closed form, Gaussian views with a shared latent and view-specific noise, and we train encoders with the joint contrastive objective that bounds total correlation. We then read the gap between the objective's value and the true total correlation as the number of models grows from three to twelve and as the embedding dimension grows, and we compare the gradient direction of the objective with that of the true quantity, since the bound is only useful if its optimum sits near the true optimum.
CONTROLS: A comparison with pairwise InfoNCE summed over all pairs and with the existing Gramian loss, a reference run with the true total correlation optimised directly where it is tractable, the same setting repeated with the number of negatives varied, and the bound gap measured against the closed-form value at every model count, over five seeds.
COST: 60
PREDICTION: The gap should stay small up to a dozen models and shrink with more negatives, with gradients aligned with the true ones. A gap that grows with the model count faster than for the pairwise sum refutes the usefulness of the bound.

TITLE: Probing the shared latent recovered by a total-correlation contrastive objective
PROPOSAL: On synthetic Gaussian views that share a latent variable and carry view-specific noise, where the total correlation among the views' representations has a closed form, we train encoders with the joint contrastive objective that bounds total correlation, for three to twelve models and several embedding dimensions. We then fit a linear probe from each encoder's output to the shared latent, measure retrieval recall across encoders, and track how both quantities change with the model count and the embedding dimension, since the objective is only useful if the recovered representations expose the latent cleanly.
CONTROLS: A comparison with pairwise InfoNCE summed over all pairs and with the existing Gramian loss, a reference run with encoders trained on the shared latent directly where it is available, the same setting repeated with the number of negatives varied, and linear-probe accuracy on the shared latent measured against the pairwise sum at every model count, over five seeds.
COST: 60
PREDICTION: Probe accuracy should stay high up to a dozen models and rise with more negatives, with retrieval recall following. A probe accuracy that drops with the model count faster than for the pairwise sum refutes the usefulness of the objective.

TITLE: Uploading embeddings only on drift to cut communication in federated alignment
PROPOSAL: We let each heterogeneous user upload its public-data embeddings only when they have drifted from the last uploaded version by more than a threshold in cosine distance, and let the server update alignment targets from whatever embeddings are current, so that traffic follows the pace of change and not a round clock. Users have different backbones and tasks, and the question is whether accuracy survives when most rounds carry few uploads. We measure per-user accuracy against bytes sent and received, with the threshold varied from strict to loose.
CONTROLS: A comparison with uploads every round at matched final accuracy and with uploads at a fixed period chosen to send the same bytes, a reference run with local training alone, the same setting repeated with the threshold varied across a wide range, and accuracy measured against total bytes on one curve per user, over five seeds.
COST: 130
PREDICTION: Drift-triggered uploads should reach the accuracy of every-round uploads at a small fraction of the bytes, and should do better than a fixed period at the same bytes. The scheme is disproved if a fixed period with the same bytes reaches the same accuracy, or if accuracy falls sharply at every threshold that saves traffic.

TITLE: Drift-triggered embedding uploads for heterogeneous federated users
PROPOSAL: Each user, with its own backbone and task, keeps a copy of the embeddings of the public collection it last sent and sends a fresh copy only once the cosine distance to that copy passes a threshold, while the server recomputes alignment targets from the latest copies it holds; the public collection stays fixed throughout. We ask whether users keep their accuracy when uploads become sparse, and we chart per-user accuracy against rounds for several thresholds, from strict to loose, together with the share of rounds in which each user sends anything, to see how upload patterns differ between backbones.
CONTROLS: A comparison with uploads processed on a server with twice the worker threads at matched final accuracy and with uploads aggregated in a different user order, a reference run with the embeddings stored in half precision on the server, the same setting repeated with the threshold varied across a wide range, and accuracy measured against total rounds on one curve per user, over five seeds.
COST: 130
PREDICTION: Drift-triggered uploads should keep accuracy close to every-round uploads with few uploads per user, whatever the server threads or the user order. The scheme is disproved if accuracy shifts with the aggregation order, or if accuracy falls sharply at every threshold that saves uploads.

TITLE: Does cross-task transfer need in-domain public data for heterogeneous users
PROPOSAL: We ask how far the unlabelled public collection that users embed can be from their local tasks before joint alignment stops transferring knowledge across tasks and architectures. Users with different backbones train on medical images, satellite scenes and product photos, and the public collection is drawn in turn from each of these domains, from generic natural images, and from synthetic textures. We measure each user's gain over local training as a function of the distance between public and local domains, estimated with a domain classifier, and we record the alignment loss reached at the end of training for every public collection.
CONTROLS: A comparison with local training on each user's own backbone at matched epochs and with pairwise alignment on the same public collection, a reference run with the public collection drawn from the user's own domain, the same setting repeated with users of different architectures and tasks held fixed while the public collection changes, and gains measured against the domain distance on one curve per user, over five seeds.
COST: 320
PREDICTION: Gains should decline smoothly with domain distance and stay positive for generic natural images, while synthetic textures should give little at best. The reading fails if gains with textures match gains with in-domain data, or if any user loses accuracy relative to local training at every distance.

TITLE: Aligning users whose embedding dimensions differ by orders of magnitude
PROPOSAL: Users whose encoders output anywhere from sixty-four to four thousand dimensions cannot be aligned without a map into a common space, and the question is whether a small projection head learned by each user, trained on the alignment target alone, is enough for cross-task transfer or whether the map must be learned jointly on the server. We give heterogeneous users image and text tasks, let each learn a projection into a common space of a few hundred dimensions, and measure per-user accuracy and the alignment reached, with the common dimension varied and the ratio between native and common dimensions recorded for every user.
CONTROLS: A comparison with projections trained on the local task loss only and with a shared random projection of the same output dimension, a reference run with local training alone, the same setting repeated with the common dimension varied from thirty-two to one thousand, and transfer measured against the encoders' native dimension ratio on one curve per user, over five seeds.
COST: 210
PREDICTION: Learned projections should transfer well for all users at a modest common dimension, and the random projection should give part of the gain only for users with large encoders. The design is contradicted if the random projection matches the learned one for every user, or if transfer shrinks with the dimension ratio under every common dimension.

TITLE: Per-user projection heads for federated alignment across embedding dimensions
PROPOSAL: Encoders in a heterogeneous federation emit anywhere from sixty-four to four thousand dimensions, so each user learns a small projection head into a common space of a few hundred dimensions, trained on the alignment target it receives from the server, and we study whether these heads let knowledge move between image and text users whose tasks differ. We record per-user accuracy, the alignment value reached and the training time of each head as the common dimension changes, and we ask whether the heads behave the same when started from different initialisations or when a normalisation layer is added.
CONTROLS: A comparison with projections started from two random initialisations and with a projection of the same output dimension that adds a normalisation layer, a reference run with the projection trained for twice as many rounds, the same setting repeated with the common dimension varied from thirty-two to one thousand, and transfer measured against the projection training time on one curve per user, over five seeds.
COST: 210
PREDICTION: Learned projections should transfer well for all users at a modest common dimension, and the heads should converge to the same alignment value from either initialisation. The design is contradicted if the two initialisations reach different accuracies for every user, or if transfer shrinks with training time under every common dimension.
