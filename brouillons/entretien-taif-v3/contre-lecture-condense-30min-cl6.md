## 2. Lisibilité

Une phrase de plus de 35 mots (cellule « Porte interne », 36) : couper après « juge texte préparé ». Termes non définis → dire : *statistique de surveillance* → « chaque règle de calcul qu'applique un moniteur » ; *puissance* → « ce qu'un nul exclut et n'exclut pas » ; *sondes, activations* → « lecteurs de l'état interne du modèle » ; *aire minimale détectable 0,63* → « un effet au moins moyen (0,5 = hasard, 1 = parfait) » ; *notes utilisables* → « note lisible dans l'échelle demandée » ; *lecture séquentielle, agrégation, token* → « lire toute la trajectoire et cumuler les indices, au lieu d'un seul point du texte » ; *0.38* (Q3) → « 0.38 recall at one per cent false alarms » ; *primed* → « given a description of the threat and example transcripts » ; *bases à sondes, juge texte préparé, garde, mode par mode* (§2) → « deux comparateurs qui lisent aussi l'intérieur du modèle, un juge sur texte à qui l'on a décrit la menace ; la sonde ne gagne pas en déclenchant plus de fausses alertes ; le gain doit se voir sur chaque type de sabotage » ; *collisionneur* → « tours où trois familles de modèles se contredisent » ; *pôle de recherche automatique* → « un agent qui propose lui-même des expériences » ; *adversaire scellé* → « attaques conçues à part, sous scellés avant la porte » ; *vérification formelle* → « preuves vérifiées par machine » ; *lignée d'agents, quarantaine* → « équipe d'agents déléguée » ; « mis à l'écart, intouché, pour audit ». Illisible en une lecture : la cellule « Travail publié le plus proche » (§3) → trois phrases ; « la carte demande quelle supposition a cassé » (§4) → « la carte liste ce que chaque moniteur suppose ; le nul nous dit d'aller voir laquelle a lâché ».
