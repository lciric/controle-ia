## Métrique

- **Format** : action valide au sens de `lire_action` et applicable à l'état (code cité) ; part sur toutes les actions (agent honnête).
- **Décomposition de variance** (C.1, adaptée à un générateur) :
  - run A : épisodes, notés une fois ;
  - run B : mêmes ensembles finaux que A, notés une seconde fois ;
  - run C : nouveaux épisodes, mêmes tâches, notés une fois.
  - Estimateurs : σ²_ε = V[sA − sB]/2 ; σ²_β = Cov[sA, sC] ; σ²_δ = Cov[sA, sB] − Cov[sA, sC] ; V[s] = σ²_β + σ²_δ + σ²_ε. Parts rapportées à V[s].
  - Intervalles : rééchantillonnage des tâches (2 000 tirages, percentiles à 95 %).
- **Score d'ensemble** : `rubrique.score_sur_100` (formule fixe) sur les notes de l'invite b0 (H.3 + H.4, assemblage de `juges.py`) ; une réponse incomplète compte comme manquante (taux rapporté), jamais imputée.
- **Cibles** :
  - contrôles : part des contrôles semés de la tâche présents dans au moins une proposition de l'ensemble final ;
  - coût : log10 du coût déclaré sur la référence, par proposition valide ;
  - directions : part des ensembles qui contiennent au moins une proposition appariée à une direction féconde, et part des propositions appariées à une direction stérile.
- **Appariement** : juge 8B, question fermée, P(oui) renormalisée sur {oui, non}, seuil 0,5. Validation sur un sous-échantillon de 200 paires (proposition, cible), tiré par graine et stratifié par famille, étiqueté par un sous-agent neuf du modèle de la session qui ne voit pas les scores : kappa de Cohen avec intervalle par rééchantillonnage.
