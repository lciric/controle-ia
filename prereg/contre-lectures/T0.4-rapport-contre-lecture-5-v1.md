  - Même code conservé en v02 U15 ; v16 (5).
- Portée :
  - pas une régression : au commit 92e2f99, `set -e` propageait déjà 137, sans consignation ;
  - improbable : au moins 96 Go de mémoire vive ; l'étape gourmande est le run Python, dont le 137 est absorbé par `lancer` (sortie 1) ;
