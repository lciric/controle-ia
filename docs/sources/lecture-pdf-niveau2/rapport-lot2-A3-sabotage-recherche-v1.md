**Identité.**

- Auteurs (5) : Eric Gan, Aryan Bhatt, Buck Shlegeris, Julian Stastny, Vivek Hebbar ; tous Redwood Research. [2604.16286v2 p. 1] « Eric Gan Aryan Bhatt Buck Shlegeris Julian Stastny Vivek Hebbar »

**Antériorité (R8).**
- **H1** : n'occupe pas. Aucun bras boîte blanche ; seuls des auditeurs boîte noire (modèles, humains). Les sondes d'activation n'y figurent que comme objet de l'une des bases de code sabotées : [2604.16286v2 p. 24] « This experiment tested whether activation probes could detect when models are sandbagging. » Utile comme base boîte noire sur du sabotage de recherche (choix de conception difficiles à juger), en audit a posteriori.
- **H2** : n'occupe pas (une crédence par base de code ; ni score par action, ni accumulation, ni seuil à 1 % de faux positifs).
- **HC1** : voisin, n'occupe pas. L'annexe H teste des sabotages « par persuasion » (justifications écrites dans le code et l'article) contre des auditeurs modèles : un seul niveau de pression, mesure par aire sous la courbe et taux de correction, ni loi de déférence, ni destination libre, ni verdict par probabilité du jeton : [2604.16286v2 p. 38] « Performance did not change substantially with persuasion. »
- **Lemme d'additivité, théorème négatif, transposition jeton → action, HC2b, papier B** : rien.
- Le sandbagging est explicitement hors du périmètre des sabotages construits : [2604.16286v2 p. 33] « Sandbagging: Rather than intentionally constructing a story for the key findings, the researcher could conduct research carelessly. »
