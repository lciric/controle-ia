== Extraction du texte (une sortie par PDF, nom = nom du PDF + « -pages.txt »)
Commande, page par page, pour p de 1 au nombre de pages donné par pdfinfo :
    printf '======== PAGE %d ========\n' p
    pdftotext -layout -enc UTF-8 -f p -l p FICHIER.pdf - | tr -d '\f'
    printf '\n'
pdftotext version 24.02.0 (poppler). Le séparateur « ======== PAGE N ======== » porte le numéro de page du PDF ;
c'est ce numéro que citent les notes, avec la page de la revue entre parenthèses quand elle est imprimée.
Contrôle : nombre de séparateurs égal au nombre de pages de pdfinfo pour les cinq fichiers (81, 157, 28, 4, 120).
Limite connue : le texte des figures de la version 1 d'arXiv est parfois illisible (police non décodée) ; les légendes le sont.
