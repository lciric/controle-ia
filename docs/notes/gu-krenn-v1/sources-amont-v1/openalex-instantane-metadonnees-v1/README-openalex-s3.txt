OpenAlex snapshot
=================
The complete OpenAlex database as downloadable files, released once a quarter.

Data:      data/jsonl/ and data/parquet/  (two complete copies, partitioned by updated_date)
Manifests: data/jsonl/manifest.json, data/parquet/manifest.json  (written last; present = release complete)
History:   RELEASE_NOTES.txt
License:   LICENSE.txt (CC0)
legacy-data/ is the frozen pre-2026 layout (incl. merged_ids/) and is not updated.

Docs: https://help.openalex.org/access/snapshot/
Sync: https://help.openalex.org/access/sync/
