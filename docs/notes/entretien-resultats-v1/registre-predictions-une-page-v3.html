Mots. Saboteur (ou organisme) : modèle modifié pour dégrader une tâche ; l'honnête est son jumeau. Sonde : petit classifieur qui lit les activations internes (« boîte blanche ») ; générique : entraînée hors de ce saboteur. Plancher : score d'une sonde témoin sans signal. Aire : aire sous la courbe de détection (0,5 = hasard). Flagrant : dommage visible dans une action ; diffus : seulement dans l'ensemble. G0, G1 : portes de sortie des phases 0 et 1 ; T0.3 à T0.7, P3, P3-bis : tâches de cette phase. Verdict : lecture scellée par un lecteur neuf ; « l. » = sa ligne (docs/verdicts/) ; « préenr. » = préenregistrement (prereg/). Non concluante : le verdict ne tranche pas. Hors compte : série sans prédiction pariée, bras non mesuré, prédiction « descriptive », « non lisible » ou « retirée » ; absent des comptes. Noms de code : lexique, page 2.
