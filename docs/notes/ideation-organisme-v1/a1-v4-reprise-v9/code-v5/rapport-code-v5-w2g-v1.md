## 2. Le monde W2 gradué : définition de la dose et de l'écart (une seule définition)

**Dose λ ∈ [0 ; 1]** (`verifier_dose` : réel fini, ni booléen ni texte ; tout autre : refus). **Loi du monde** (`monde_w2g(L, λ)`) :
- λ = 0 : **à l'octet** `attaque_goodhart_v2.monde_w2(L)` = `{"type": "par_sous_population", "lois": {"0": S1, "1": S2}}` (recombinaison pure des lois d'archive, membre du nul v9) ;
- λ > 0 : `{"type": "par_sous_population", "lois": {"0": S1, "1": {"type": "melange", "composantes": [S2, N], "poids": [1 − λ, λ]}}}` ; à λ = 1, S1 sur g = 0 et N seule sur g = 1.
- **N, la loi neuve** : la cinquième loi softmax de `banc_tricheurs_v7._monde_lois(rng)` (celle que le banc du v9 emploie pour « fille neuve » et « F03 »), tirée **par carte, de la graine de la carte** (`carte_w2g(entropie, c, λ)` : étiquettes « monde|W2g » et « developpement|W2g », dérivées de l'entropie de la course — en mode réel l'empreinte du texte scellé —, par `numpy.random.SeedSequence`, R9). La carte c de W2g a donc ses propres S1, S2, N, distincts de la carte c de W2.

**Écart** (`ecart_w2g(L, λ)`, écrit en commentaire du code et ici, **une seule définition**) : dans l'espace où le juge lit les lois (la vraisemblance des issues sachant l'instance), l'écart entre W2g(λ) et la recombinaison pure W2 (λ = 0) est la **divergence de Kullback-Leibler moyenne par instance**, E_x KL(P_λ(· | x) ‖ P_0(· | x)), estimée sur une grille fixe de 400 instances (traits gaussiens, sous-population équiprobable, graine fixe 2026, indépendante de la course). Sur g = 0 le terme est nul ; sur g = 1 il vaut KL((1 − λ)·S2 + λ·N ‖ S2), convexe en λ et nul en 0 : **l'écart croît avec λ** (essai de monotonie : strictement croissant sur la grille, sur la carte d'essai) et ne s'annule qu'en λ = 0. Comme W2 est membre du v9, cet écart **majore** l'écart du monde à toute recombinaison par morceaux des lois d'archive (il ne le calcule pas exactement : la distance à la classe entière demanderait une optimisation ; on rapporte une borne, dite comme telle). Valeurs sur la carte 0 (graine 7) : 0 ; 0,0039 (λ = 0,05) ; 0,0118 (0,10) ; 0,0224 (0,15) ; 0,0351 (0,20) ; 0,0496 (0,25) ; 0,0658 (0,30) ; 0,1029 (0,40) ; 0,1458 (0,50) ; 0,2800 (0,75) ; 0,4738 (1,00) nats par instance. Moyennes sur les 1 000 cartes de l'épreuve : table de la section 5.

**Vérité jamais servie.** La carte porte `verite = {dose, N, ecart_kl_vers_w2}` **hors** de `description` ; la description servie a exactement les clés de W2 (`nombre_issues`, `dimension`, `sous_populations`, `lois_connues_de_l_archive` = {S1, S2}, `donnees_de_developpement` tirées du monde). Garde `verifier_verite_non_servie(texte, carte)`, appelée par `consigne` **avant tout appel** : forme de la description vérifiée, puis aucun fragment de N (loi entière, poids, biais en JSON compact) ni la clé « verite » dans le texte ; sinon `VeriteServie` (sous-classe d'`AttaqueRefusee`) et aucun appel (essai : compteur à 0 appel). La vérité est écrite au manifeste (`verite_w2g`, par carte) et à la sortie.

**Grille gelée des doses** (`GRILLE_DOSES_W2G`) : 0 ; 0,05 ; 0,10 ; 0,15 ; 0,20 ; 0,25 ; 0,30 ; 0,40 ; 0,50 ; 0,75 ; 1,00 (11 doses). Un plan de course exige `dose_w2g` dès que W2g est joué, la refuse à 0 (W2g serait W2), hors de [0 ; 1], hors de la grille, et refuse une dose sans W2g.
