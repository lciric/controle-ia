C       ACTIVATION EXTRACTION AND PROBE TRAINING
We evaluate four open-weight models: Qwen3-32B-AWQ (Qwen Team, 2025), Llama-3.1-70B-
Instruct-AWQ-INT4 (Meta AI, 2024), DeepSeek-R1-Distill-Qwen-32B (DeepSeek-AI, 2025), and
GPT-OSS-20B (OpenAI, 2025a) (compute details in Appendix I). Qwen3-32B was used for hyper-
parameter tuning; the resulting probe configuration transfers unchanged to the other models. We
extract activations at the last token position of each agent’s public responses, across a five-layer band
in the middle of each model (e.g. layers 26–30 of 64 for Qwen3-32B), where semantic represen-
tations are strongest (Zou et al., 2023b); we report mean AUROC across these layers. For C ORE,
for each agent we extract the last token of system_prompt + round-N user_prompt +
round-N public message averaged over rounds N=1,2,3. For T RANSFER and S TEGO, we use
final-round activations only, where all agents receive identical user prompts, i.e. we extract the last to-
ken of system_prompt + final-phase user_prompt + final response text.

Deception probe. Following Goldowsky-Dill et al. (2025), we fit a linear probe to distinguish collud-
ing agents from honest agents. We collect activations from NARCB ENCH -C ORE collusion runs only
(public channel), giving a dataset of activation vectors xi ∈ Rd with labels yi ∈ {honest, colluder},
balanced by downsampling the majority class. We standardise activations to zero mean and unit
variance, then train a logistic regression classifier. The normalised weight vector defines a deception
direction. For a new agent j, we compute a scalar deception score:
                                                  sj = z̄j · d                                               (8)
where higher scores indicate a more colluder-like internal state. A null probe trained on a random split
of honest agents scores near chance, confirming the probe is not picking up incidental differences.
